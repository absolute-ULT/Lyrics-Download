# HE-Music 歌词下载助手

一个无需构建、无需第三方依赖的 Chrome Manifest V3 扩展，为 `https://y.hmusic.top/` 的原生“下载歌曲”窗口加入歌词选项。

## 安装到 Chrome

### 方法一：拖入单个 ZIP 文件

1. 使用 **v1.0.1 或更新版本** 的 ZIP 安装包。
2. 打开 `chrome://extensions/`，开启右上角的 **开发者模式**。
3. 将 ZIP **拖到扩展管理页的空白区域**，不是拖到普通网页或地址栏。
4. 按浏览器提示完成加载，然后刷新 HE-Music 网页。

此版本 ZIP 的根目录直接包含 `manifest.json`。v1.0.0 包在外面多套了一层 `extension` 文件夹，不能用于直接拖入安装。Chromium 的开发者安装入口支持解压拖入的 ZIP；如果浏览器版本或组织策略禁止这一入口，请用下面的本地开发方式，不要修改浏览器安全策略。这里提供的是开发者加载方式，不是 Chrome Web Store 商店安装或通用 CRX 分发。

### 方法二：加载现成的扩展文件夹

1. 打开 `chrome://extensions/`，开启 **开发者模式**。
2. 点击 **加载已解压的扩展程序**。
3. 选择本项目的 **extension** 文件夹，里面应直接包含 `manifest.json`。
4. **刷新已经打开的 HE-Music 网页**。

如果解压的是 v1.0.1 ZIP，请直接选择解压后包含 `manifest.json` 的目录，里面不再套一层 `extension` 文件夹。无需运行 `npm install`。

### 更新已有版本

如果原先直接加载本项目的 `extension` 文件夹，在扩展管理页找到“HE-Music 歌词下载助手”，点击卡片上的 **重新加载（圆形箭头）**，然后刷新音乐网页即可。新的歌词选项卡片会显示 **歌词助手 v1.0.5**。不要只刷新网页而不重新加载扩展，也不要同时启用两份插件。

## 使用

在歌曲右键菜单中选择 **下载歌曲**，原弹窗里会多出一张“歌词助手”卡片：

- **同时下载歌词**：勾选后，点击原站“下载歌曲”，会额外获取并保存这首歌的歌词。取消勾选只下载音频。
- **LRC · 带时间轴**：保留行级时间标签，并清理酷我等来源的逐字标记，适合音乐播放器读取。
- **TXT · 纯文本**：移除时间标签与歌词头信息，方便阅读。
- **附带翻译 / 附带罗马音**：来源提供时按相同时间位置合并；来源没有时不会虚构内容。
- **仅下载歌词**：不开始音频下载，单独保存歌词文件。

点工具栏中的插件按钮可设置默认选项，也可选择“下载时询问保存位置”。这些设置仅保存在本机。

### 文件名与保存位置

歌词的基础文件名跟随网站“歌手 - 歌名”“歌名 - 歌手”或“歌名”的命名设置。文件以 UTF-8 BOM 编码保存，以兼容 Windows 常用文本编辑器。

Chrome 会把歌词当作一个独立的下载文件处理，默认保存到浏览器的下载目录。如为音频手动选择了其他文件夹，请为歌词选择同一个文件夹。浏览器对已有同名文件可能自动添加 `(1)` 等后缀，因此重复下载时请自行核对两个文件的名字。

v1.0.1 增加了 `onDeterminingFilename` 最终命名建议，解决歌名丢失的问题，但 LRC 下载仍使用 `text/plain`，Chrome 后续的 MIME 文件名处理仍可能将 `.lrc` 改回 `.txt`。

v1.0.2 将两种格式的下载类型分开：LRC 使用 `application/x-lrc`，TXT 使用 `text/plain`。两者都保留最终命名建议；TXT 输出会去掉时间轴，而不是仅修改后缀。此处理只适用于本扩展发起的歌词下载，不修改音频或其他插件的文件名。

新版还会查询 Chrome 的实际下载记录，最多等待 10 秒，核对最终歌名与后缀，允许浏览器的重名序号。只有下载状态为完成且文件名核对通过，才显示“歌词已保存”；未完成、无法核对或实际后缀不对会分别说明，不再把请求文件名当作保存结果。开启“询问保存位置”时，允许手动修改歌名，但仍核对格式后缀。已经下载的旧文件不会被自动修改。

## v1.0.5 歌词下载修复（2026-11-25）

默认保存时，插件会在下载链接上直接指定安全歌名和 `.lrc` / `.txt` 后缀，修复部分 Chrome 环境将歌词保存为无后缀的“下载”的问题。后台按这一次下载的唯一地址核对结果；没有下载记录时会提示检查浏览器拦截。开启“询问保存位置”时仍走原有的浏览器另存为流程。无需新增权限，也不会修改旧文件。

保留 v1.0.4 安装包的站点适配：从同源 `stores-*` 和 `mainWindow-*` 中选择提供歌词接口的模块。仅下载歌词和随音频下载可用离线歌曲样例做真实 Chrome 回归测试：`node tests/download.mjs extension`（Windows，或用 `CHROME_PATH` 指向支持 `Extensions.loadUnpacked` 的 Chrome）。

## v1.0.3 网站适配修复（2026-11-10）

当前网站的歌词地址仍为 `/v1/song/lyric`。网站给歌曲链接函数增加了异步请求及结果包装，旧版只识别箭头函数最外层的请求调用，因此误报“网站歌词接口已变更”。

v1.0.3 从包含已知歌曲接口地址的实际调用中定位请求客户端，兼容 `await`、结果包装、普通函数以及压缩后的函数名。不调用音频链接函数，不参与音频处理，不读取或导出登录 token。无法识别时会明确说明是请求函数识别失败，不再断言服务器接口已改变。

已用本版识别逻辑在当前网站模块上现场获取一首实际歌曲的歌词，HTTP 200，原文含 6,125 个字符及行级时间轴；新增测试覆盖当前异步包装结构、旧版结构和误识别边界。正式扩展仍需重新加载并刷新网页后生效。

## 官方实现依据

- [Chrome downloads API](https://developer.chrome.com/docs/extensions/reference/api/downloads)：文件名决定事件及多个扩展建议的优先级。
- [Chromium 拖入安装入口](https://chromium.googlesource.com/chromium/src/+/main/chrome/browser/extensions/api/developer_private/developer_private_functions.cc)：ZIP 分支调用 `ZipFileInstaller`。
- [Chromium ZIP 安装器](https://chromium.googlesource.com/chromium/src/+/main/extensions/browser/zipfile_installer.cc)：在解压目录根部读取 `manifest.json`。

## 行为边界

- **不接管音频下载**：音质、歌曲下载权限和音频错误仍由原站处理。音频和歌词是两条独立流程：即使音频失败或取消，歌词也可能下载成功；歌词失败则不会阻止音频下载。
- **无时间标签时自动用 TXT**：不会给纯文本歌词伪造时间轴。
- **没有歌词时明确提示**：不创建空文件；网络错误、登录状态异常会给出重试提示。
- **只使用当前登录会话能够正常访问的歌词接口**：不绕过登录、验证码、付费权限或其他访问控制。
- **适配范围**：仅在 `https://y.hmusic.top/*` 注入，目前适配网站 `DownloadSong` 原生单曲下载弹窗。不同音乐来源共用这一流程；来源是否提供歌词取决于网站。暂不处理批量下载、嵌入音频标签、其他镜像域名和桌面客户端。
- 网站改版可能需要更新适配器。请仅下载你有权获取、保存和使用的内容。

## 权限与隐私

仅请求两个扩展权限：

| 权限 | 用途 |
| --- | --- |
| `storage` | 在本机保存默认选项 |
| `downloads` | 将歌词作为本地 `.lrc` 或 `.txt` 文件下载 |

没有通配的主机权限，没有第三方数据收集、分析、上传或账号同步。页面桥接器只返回歌名、歌手、文件名和允许的歌词字段；不读取或导出登录 token。后台仅接收本站顶层标签页的歌词文本，不能下载页面提供的任意网络地址。

## 开发与测试

需要 Node.js 18 或更新版本：

```bash
npm test
npm run check
npm run package
```

- `npm test`：运行 Node 内置测试，无需安装测试框架。
- `npm run check`：检查 Manifest V3 清单、资源、最小权限、脚本语法，并运行所有测试。
- `npm run package`：在 `dist` 中创建带时间戳的 ZIP，包含扩展与使用说明，不覆盖已有包。

### 手动验收清单

1. 加载扩展并刷新网站，打开任意歌曲下载弹窗，确认歌词卡片只出现一次。
2. 点击“仅下载歌词”，确认下载文件与当前选中的歌曲对应，而不是播放器正在播放的另一首歌。
3. 分别选择 LRC、TXT，检查歌词内容、时间标签、逐字标签清理及 UTF-8 中文。
4. 选择有翻译的歌曲，开关翻译/罗马音检查输出。
5. 取消“同时下载歌词”，正常下载歌曲，确认不会额外创建歌词文件。
6. 勾选后下载歌曲，确认两个独立文件；音频原有音质选项保持不变。
7. 在网站设置切换命名顺序，重新下载歌词，检查文件名跟随设置。
8. 通过插件弹窗修改默认选项、刷新网页，确认设置仍然保留。
9. 遇到无歌词、断网、取消保存等情况，确认有提示且不影响原站操作。

### 本机临时预览

`node tools/preview.cjs` 可提供仅绑定 `127.0.0.1:18765` 的开发预览资源。它用于在实际页面上联调界面与歌词接口，不会安装扩展。预览使用内存设置和浏览器普通文本下载来代替 Chrome 扩展 API，不能替代真实的“加载已解压扩展”验收。预览标有“临时预览”，刷新网页后消失。
